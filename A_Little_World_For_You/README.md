# A Little World For Cinna ♡

A small romantic 2D Pixel Art platform game made with HTML, CSS and JavaScript.

## Run the game
1. Extract this ZIP file.
2. Put Cinna's photo named **pic.jpg** in the same folder as `index.html`.
3. Open `index.html` in Chrome or another modern browser.

## Controls
- Left / Right arrows or A / D: move.
- Space, Up arrow or W: jump.
- On mobile: use the on-screen buttons.

## Personalization
- Birthdays: 26 / 11 / 2004 and 30 / 01 / 2005.
- Her name in the game: Cinna.
- The flower garden includes lilies, peonies, tulips and daisies.
- Edit the final letter in `index.html`.
- Edit level messages and game behavior in `game.js`.

## Important photo note
The page loads the photo using the relative path `pic.jpg`. Put the image in the same folder as `index.html`. Do not use the Windows absolute path in the website code; browsers cannot reliably load a file from a specific Windows user's Downloads folder when the project is moved or shared.
